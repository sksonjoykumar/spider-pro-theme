# Support

Official contact details found in the theme metadata:

- Email: support@spiderthemes.com
- Documentation: https://sonjoykumar.vercel.app/blogs/spider-pro-shopify-theme-english

When requesting help, include the Spider Pro version, affected template/section,
reproduction steps, expected and actual behavior, browser/device details, and
sanitized screenshots or console output.

Never send passwords, Shopify access tokens, payment information, or customer
personal data in a support request.

The uploaded theme metadata does not define support hours, response times,
support duration, pricing, or update entitlements. Confirm those in the
applicable commercial agreement.
