# Security Policy

Spider Pro is a private, proprietary Shopify theme repository.

## Reporting a vulnerability

Do not publish suspected vulnerabilities, credentials, private store data, or
security-sensitive details in a public issue or discussion.

Send a private report to **support@spiderthemes.com** with the subject
`Spider Pro Security Report`. Include the affected file or feature, impact,
reproduction steps, and sanitized evidence. Never include live access tokens,
customer data, passwords, or private keys.

## Repository security

- Keep the complete Spider Pro repository private.
- Enable two-factor authentication for GitHub accounts with repository access.
- Grant collaborators only the access they need and revoke it when no longer
  required.
- Never commit `.env` files, API credentials, Shopify access tokens, private
  keys, or customer exports.
- Rotate credentials if exposure is suspected.
- Review GitHub Actions permissions and third-party actions before use.

No security response-time commitment is defined in the supplied theme metadata.
