## Feature overview

The source includes:

- Storefront header, navigation, announcement bar, premium footer, mobile toolbar, and back-to-top.
- Product and collection templates, grids, carousels, collection showcases, filtering, sorting, search, and predictive search.
- Product media, Quick View, Quick Add, wishlist, product comparison, sticky add-to-cart, product bundles, recently viewed/purchased, product tabs, specifications, size guide, and fit finder.
- Cart drawer, cart page, cart shipping tools, customer account templates, localization, age verification, cookies, and Shop Protect.
- Campaign banners, countdowns, popups, newsletter, gift guide, shoppable video, social gallery, testimonials, quiz, before/after slider, brand storytelling, wholesale inquiry, order tracking, product registration, retail locations, slideshow, and marquee.

## Installation

1. Back up the current store theme.
2. Use the Shopify-theme-only ZIP, not this full GitHub repository ZIP.
3. Upload through Shopify Admin → Online Store → Themes → Add theme → Upload ZIP.
4. Preview the unpublished theme and configure Theme Editor settings.
5. Test navigation, product variants, cart, forms, and enabled features before publishing.

See [docs/INSTALLATION.md](docs/INSTALLATION.md).

## Development

```bash
shopify theme dev --store your-store.myshopify.com
shopify theme check
shopify theme push --unpublished --store your-store.myshopify.com
```

Replace the example store domain with an authorized development store. Do not publish without owner approval.
